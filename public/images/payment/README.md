# Logos moyens de paiement

`fedapay.svg` est un **placeholder** dessiné à la main. Remplacez-le par le logo
officiel FedaPay (même nom de fichier, `public/images/payment/fedapay.svg`), sans
modification de code : `components/ui/PaymentBadges.tsx` le référence déjà.

Format conseillé : SVG, wordmark sur fond transparent, hauteur de tracé ~40 px.
Marque officielle disponible sur la page de presse / brand de FedaPay.
